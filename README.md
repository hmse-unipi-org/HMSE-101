## Cara Menjalankan Kode

### Windows
```cmd
python hello.py
```

### Linux / Mac
```bash
python3 hello.py
```

Atau jalankan langsung dari editor teks kamu.

## Daftar Materi

| File | Materi | Penjelasan |
|------|--------|------------|
| `hello.py` | **Program Pertama** | Menampilkan teks ke layar menggunakan `print()` dan mengenal komentar satu baris serta multi-baris. |
| `variabel.py` | **Variabel** | Menyimpan data ke dalam variabel dan menggabungkannya untuk menampilkan output yang rapi. |
| `input.py` | **Input Pengguna** | Meminta input dari pengguna dengan `input()` dan mengolah data penjumlahan sederhana. |
| `operator.py` | **Operator Aritmatika** | Penjumlahan, pengurangan, perkalian, pembagian, modulus, pembagian bulat, dan perpangkatan. |
| `tipe-data.py` | **Tipe Data** | Boolean, string, integer, float, hexadecimal, complex, list, tuple, set, dan dictionary. |
| `tukar.py` | **Menukar Nilai Variabel** | Teknik klasik menukar nilai dua variabel menggunakan variabel bantu. |

## Urutan Belajar yang Disarankan

1. `hello.py` — biasakan diri dengan Python dan cara menjalankan program.
2. `variabel.py` — pahami cara menyimpan data.
3. `tipe-data.py` — kenali jenis-jenis data yang bisa kamu pakai.
4. `operator.py` — belajar mengolah data dengan operator.
5. `input.py` — buat program yang interaktif.
6. `tukar.py` — latihan logika sederhana.

## Tips Belajar

- **Jangan hanya salin kode.** Ketik ulang setiap contoh agar terbiasa dengan sintaks Python.
- **Bodohi kodenya!** Ubah nilai, tambah variabel, atau coba kombinasikan beberapa konsep — lalu lihat apa yang terjadi.
- **Komentar adalah sahabatmu.** Setiap komentar di kode menjelaskan tujuan baris tersebut. Baca baik-baik.
- **Error itu wajar.** Jika programmu error, baca pesannya dengan teliti — Python biasanya sudah memberi petunjuk di baris mana masalahnya.
